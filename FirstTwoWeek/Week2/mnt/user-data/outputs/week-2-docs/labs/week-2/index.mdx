# Week 02 — Hands-on Labs

Two labs this week. Together they cover the **full production API engineering cycle**: build → authenticate → containerize → deploy → instrument → observe.

---

## Labs Overview

| Lab | Title | Time | Difficulty |
|-----|-------|------|------------|
| [Lab 2.1](./gemma-api-hf-spaces-google-auth) | Gemma Model API on HuggingFace Spaces with Google Auth | ~3–4 hrs | ⭐⭐⭐ |
| [Lab 2.2](./fastapi-observability-grafana) | FastAPI Observability + Live Grafana Dashboard | ~2–3 hrs | ⭐⭐⭐ |

---

## What You'll Have After Both Labs

```
Lab 2.1 output:
  ✅ Live FastAPI service on HuggingFace Spaces
  ✅ Gemma 3 (local) or API endpoint for text generation  
  ✅ Google OAuth — only @ds.study.iitm.ac.in emails can access
  ✅ JWT-protected /generate endpoint

Lab 2.2 output:
  ✅ Same FastAPI service instrumented with Prometheus
  ✅ OpenTelemetry traces exported to Jaeger
  ✅ Live Grafana dashboard with request rate, latency, error rate panels
  ✅ Alert rule that fires when error rate > 5%
```

## Prerequisites

Before starting, make sure you have:

- [ ] UV installed (`uv --version`)
- [ ] Docker Desktop installed and running
- [ ] A Google account (for OAuth)
- [ ] A HuggingFace account (free) at [huggingface.co](https://huggingface.co)
- [ ] Git configured (`git config --global user.email "..."`)
