# Lab 1: Build a Data Pipeline
**Difficulty:** Beginner · **Estimated time:** ~2 hours

## Objective
Build a Python pipeline that downloads a public dataset, validates and cleans it, and uploads to GCS with versioned paths.

## Submission
Submit a GitHub repo link with `pipeline.py`, `requirements.txt`, `Dockerfile`, and `README.md`.

## Grading rubric
| Criterion | Points |
|---|---|
| Pipeline runs end-to-end | 30 |
| Data validation catches bad rows | 20 |
| GCS paths follow conventions | 20 |
| All steps logged | 15 |
| Docker container runs | 15 |
| **Total** | **100** |
