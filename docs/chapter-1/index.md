# Chapter 1 — MLOps Foundations
This chapter covers the foundational concepts and tools of MLOps.

## In this chapter
| Page | What you'll learn |
|---|---|
| [Overview](./overview) | What MLOps is and how it differs from traditional ML |
| [Environment setup](./environment-setup) | Git, Docker, Python venvs, and VS Code |

## Learning outcomes
After completing this chapter you will be able to:
- Explain the key differences between a Jupyter notebook workflow and an MLOps workflow.
- Set up a clean, reproducible development environment.
- Write a Python script that trains a model and saves it as an artifact.
- Run that script inside a Docker container.
