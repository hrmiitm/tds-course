# Welcome to TDS
**Tools in Data Science** is a practical course run by the Online Degree Programme at IIT Madras.
It teaches the tooling that modern data scientists and ML engineers use every day — from version
control and containerisation all the way to cloud deployment and monitoring.

## What you will learn
By the end of this course you will be able to:
- Set up a reproducible ML development environment using Git, Docker, and virtual environments.
- Build and run automated data pipelines with proper logging and error handling.
- Package and containerise Python applications and deploy them to Google Cloud Run.
- Use BigQuery ML to train and evaluate models at scale without a local GPU.
- Monitor deployed models using Cloud Logging and set up alerting.

## How the course works
Each chapter contains:
1. **Reading** — explanations with diagrams and code examples.
2. **Step-by-step walkthroughs** — commands you can run along with the text.
3. **A lab** — an assessed exercise you submit through the course portal.

## Using the coding terminal
This site has a built-in coding terminal. Press **Ctrl+`** (or click the terminal button in the
bottom-right corner) to open a panel that embeds your local VS Code server.

## Prerequisites
- A laptop running macOS, Linux, or WSL2 on Windows.
- Python 3.11+ installed.
- A Google account (for GCP free tier access).
- Basic familiarity with Python and the command line.
